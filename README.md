# Python Mini Projects

A collection of small, beginner-friendly Python programs that turn programming fundamentals into practical, interactive exercises. Each project focuses on a clear task and helps practice problem-solving, conditions, loops, functions, input validation, and working with data.

This repository is for learning and experimentation. These projects are educational examples, not production-ready software.

## Projects Included

| Project | File | What it does | Concepts practiced |
| --- | --- | --- | --- |
| 1. Guess the Number | `Project 1/guess_the_number.py` | Lets the player guess a hidden number. | Input, conditions, loops, comparisons |
| 2. ATM Simulator | `Project 2/atm_simulator.py` | Simulates basic ATM-style interactions. | Menu-driven programs, conditions, numeric input |
| 3. Student Grade Calculator | `Project 3/student_grade_calculator.py` | Calculates or displays student grade information. | Arithmetic, conditions, input handling |

## Getting Started

### Requirements

- Python 3 installed
- A code editor or terminal, such as VS Code

The projects are designed to use Python's standard library and generally do not require installing third-party packages.

### Run a project

1. Clone or download the repository.
2. Open the repository folder in your code editor.
3. Choose a project folder.
4. Run its Python file from the terminal. For example:

```bash
python "Project 1/guess_the_number.py"
```

You can run any other project by replacing the example path with its file path. On some systems, use `python3` instead of `python`.

Most projects are independent programs, so run one at a time. Follow the prompts shown in the terminal.

## Learning Goals

- Practice core Python syntax through complete, small programs.
- Build confidence with loops, conditions, functions, and collections.
- Learn to validate user input and handle common errors.
- Break a practical task into smaller steps.
- Improve and extend each project as your skills develop.

## Important Notes

- **Educational use:** These projects are for learning and demonstration.
- **Banking system:** The balance is not connected to a real bank or persistent database. The program is not suitable for real financial transactions.
- **Hospital management:** The sample patient records are stored in memory and are not saved to a database. Do not use real or confidential patient information.
- **Password checker:** It checks basic password composition rules; it does not determine whether a password has been exposed or is safe against every attack.
- **Authentication:** The mini banking example is a learning exercise, not a secure production authentication system.
